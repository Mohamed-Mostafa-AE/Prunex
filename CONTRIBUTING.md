# Contributing

Thanks for taking the time to look at Prunex.

The project is currently published for source inspection and review. Contributions are not being accepted at this time. If you find a reproducible bug or have a technical question, open an issue with the relevant details.

Please do not include passwords, access tokens, private keys, personal data, or other sensitive information in issues or pull requests. For security problems, follow the instructions in [SECURITY.md](SECURITY.md) and report them privately.

Before opening a report, check whether the issue is already documented in the README or the project notes. For a useful bug report, include your operating system, compiler or browser version, the steps to reproduce the problem, and the output you observed. Remove any personal or sensitive information from logs first.
