# Project name

The name **Prunex** was coined from two ideas associated with the engine's design:

- **PRUN** refers to pruning in game-tree search, specifically alpha–beta pruning.
- **EX** refers to competitive execution.

This records the intended naming origin. It is not a formal acronym, language claim, or technical definition.

The native engine's use of alpha–beta search is documented separately in the engine architecture and source code.
