INSIDE THE ENGINE

Built from
the board up.

Prunex 0.8.0 is a chess engine written from the ground up in C++20. Its source includes the position model, legal move generation, search, evaluation, and Universal Chess Interface (UCI) support.

The search uses Zobrist hashing, a transposition table, iterative deepening, aspiration windows, principal-variation search, move ordering, late-move reductions, and quiescence search. The evaluation uses a tapered positional model.

The native project is built with CMake. Its Windows GUI uses the Win32 API, while the engine can also be driven through its UCI interface.

About the name: The name draws on two ideas: “PRUN” refers to alpha–beta pruning, and “EX” refers to competitive execution. This is the project's naming inspiration, not a formal technical acronym.

PERFORMANCE STANDARD

Strength is earned in testing.

Engine strength is established through repeatable games, fixed time controls, balanced colors, diverse opening positions, and enough samples to report a meaningful rating range.

Prunex publishes measured results only when the test configuration, game count, and uncertainty can be inspected. A single match score or a longer search setting is not, by itself, proof of a rating advantage.
