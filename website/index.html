INSIDE THE ENGINE

Built from
the board up.

Prunex 0.5.1 is a chess engine written from the ground up in C++20. Its source includes the position model, legal move generation, search, evaluation, and Universal Chess Interface (UCI) support.

The search uses Zobrist hashing, a transposition table, iterative deepening, aspiration windows, principal-variation search, move ordering, late-move reductions, and quiescence search. The evaluation uses a tapered positional model.

The native project is built with CMake. Its Windows GUI uses the Win32 API, while the engine can also be driven through its UCI interface.

TESTING

Checked as it grows.

The native engine has 44 regression tests covering move generation, special moves, search positions, and UCI commands.

Recorded Linux builds passed with GCC Release, Clang Release, and AddressSanitizer/UndefinedBehaviorSanitizer. The GCC static-analysis build completed without diagnostics.

The Windows desktop application still needs a full manual test on Windows 10 or 11. The current limitations and test coverage are listed in the project notes.
